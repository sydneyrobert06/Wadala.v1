# Wadala.v1

This repository contains a fresh, GitHub Pages-ready Wadala East simulation dashboard.

Files:
- `index.html` — the main simulation + financial dashboard

What is in the model:
- Plot area and road-width controls
- 3D-style site simulation for a Wadala plot
- Win-win TIF/UCF dashboard driven by the current data in the latest Wadala model
- Deal matrices and stress test values derived from the CSV model values supplied

How to publish via GitHub Pages:
1. Open the repository on GitHub.
2. Go to Settings → Pages.
3. Set Source to `Deploy from a branch`.
4. Select branch `main` and folder `/root`.
5. Save.

Then the page will be published at:
https://sydneyrobert06.github.io/Wadala.v1/

This version intentionally starts fresh and does not depend on the earlier mockup images or previous UI directions.

# Wadala.v1

This repository now contains a GitHub Pages-ready dashboard for the combined Wadala simulation and financial model.

Files:
- `index.html` — single-file dashboard for GitHub Pages

To publish it via GitHub Pages:
1. Open the repository on GitHub.
2. Go to Settings → Pages.
3. Set Source to `Deploy from a branch`.
4. Select branch `main` and folder `/root`.
5. Save.

Once the site is published, it will be available at:
https://sydneyrobert06.github.io/Wadala.v1/

This page combines:
- the dark dashboard UI style shown in the mockup
- a 3D-styled Wadala plot simulation block
- the updated Wadala East TIF/UCF win-win financial model data
